# Responsible AI

## Intended Use

This project is intended for preliminary crop disease screening
and educational/research purposes.

## Limitations

Performance may vary because of:

- Image quality
- Lighting conditions
- Camera differences
- Crop varieties
- Disease stages
- Field conditions
- Diseases not represented in the training data

## Important

The prediction should not be treated as a definitive agricultural
diagnosis or an automatic prescription for chemical treatment.

Users should consult qualified agricultural professionals when
appropriate.
