# Dataset

This project uses the PlantVillage dataset for initial model
development and benchmarking.

The dataset contains approximately 54,000 labeled plant leaf images.

## Important

The dataset is not included in this GitHub repository.

Users should obtain the dataset from its official source and
follow its applicable license and attribution requirements.
